# 🎓 Gemma 4 기반 학생부종합전형 AI 모의면접 시스템

학교생활기록부(세특 및 탐구활동) PDF를 파싱하여 맞춤형 압박 면접 질문과 꼬리질문을 생성하고, 
면접 종료 후 대학 모집요강 기준의 종합 채점표를 산출하는 웹 서비스입니다.

## 🛠️ 기술 스택
- **UI:** Streamlit
- **LLM:** Google Gemma 4 (`google-generativeai`)
- **PDF Parser:** pdfplumber
